# ITA0520 Computer Vision — Assignment 3 (CO3, Set B)
## Museum Exhibit Logo Authentication

This project implements reproducible demonstrations for all ten tasks in the assignment.

### Important evidence note
The project uses a **synthetic, deterministic dataset** of museum-style emblem images because no real museum reference collection was supplied. All reported measurements are computed by executing the included OpenCV/NumPy code on that dataset. They are not claims about real museum exhibits. Synthetic labels identify the generated genuine/counterfeit-style variants and are used only for this controlled demonstration.

### System scenario
- Camera: 2560 × 1440 (the synthetic working crops are 256 × 256 to keep the project lightweight)
- Reference logos: 120 (the project generates one reference exemplar and 120 reference entries by deterministic augmentation for the PCA/memory exercise)
- Perspective tilt: up to 25 degrees
- Descriptor memory budget: 10 MB
- Decision target: 1 second (runtime is measured on the machine used to execute the project; it may differ on another machine)

### Run

```bash

.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
python src/run_all.py
```

The script regenerates the deterministic dataset and all results/outputs.

### Implemented task coverage
1. Resize/grayscale, denoise/normalization, contour-based perspective rectification.
2. Point-intensity glare mask, local inpainting, global CLAHE transform.
3. Binary silhouette, chain-code representation, Hu shape descriptors.
4. Sobel, Laplacian-of-Gaussian, Canny edge maps.
5. Harris, Shi–Tomasi, FAST corner detection.
6. Standard Hough, probabilistic Hough, contour-fitted dominant line.
7. ORB, SIFT (when available in the installed OpenCV build), AKAZE feature matching.
8. Nearest-neighbour matching, Lowe ratio test, ratio + RANSAC homography verification.
9. No reduction, PCA-32, PCA-64 fitted using the 120-entry reference bank plus query samples, with measured reconstruction error and storage arithmetic.
10. Template geometry, local-feature verification, and multi-view confirmation using multiple generated views.

### Interpretation and limitations
- The dataset is generated, not photographed from real exhibits.
- The synthetic counterfeit-style marks are controlled perturbations of the genuine emblem, not a representative counterfeit collection.
- Some metrics (e.g., matching acceptance, feature counts, corner repeatability proxies) are computed on these synthetic samples and should not be generalized to real-world performance.
- Perspective rectification uses detected contours and quadrilateral approximations; it can fail if the logo boundary is not sufficiently visible.
- The multi-view method uses generated views of the same query identity. A real installation would require multiple synchronized or sequential captures.
- The 1-second decision requirement must be verified on the actual deployment hardware using end-to-end camera, preprocessing, matching and storage operations.
